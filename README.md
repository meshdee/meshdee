## 🚀 Featured Project

### M-PESA Rent Wallet

**Save smart. Pay rent. Build your future.**

An independent FinTech prototype exploring how **rent savings, scheduled rent payments, digital transactions and property management** can be integrated into a connected rental ecosystem.

The project brings together:

* Business & Enterprise Architecture
* FinTech product design
* Digital payment concepts
* Application development
* API design
* Database architecture
* Property management workflows
* Data & transaction flows
* Security and risk considerations

**Project journey:**

> **Concept → Business Architecture → Application → Database → APIs → Documentation → Presentation**
